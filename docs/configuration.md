# Configuration

relift reads its own settings from `relift.toml` in the working directory (or
the file given with `-c`), then `RELIFT_*` environment variables, then flags.
Per-game data lives in each game project's `game.toml`, not here.
`relift.example.toml` lists every key. The table below is generated from the
settings struct (`relift/src/settings.rs`) by configulator; CI fails when it
is stale. The built program's own run-time settings and environment
switches are in `runtime/README.md`.

<!-- configulator:begin -->

| Key                             | Type    | Default  | Environment                            | Flag                              | Description                                                                                                                                                                                                                               |
|---------------------------------|---------|----------|----------------------------------------|-----------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `cache-dir`                     | string  |          | `RELIFT_CACHE_DIR`                     | `--cache-dir`                     | where lifted, emitted and built artifacts are cached (empty: the user cache dir)                                                                                                                                                          |
| `jobs`                          | integer | `0`      | `RELIFT_JOBS`                          | `-j`, `--jobs`                    | worker threads for every parallel stage of a build: analysis, emit and compile (0: one per CPU)                                                                                                                                           |
| `runtime-dir`                   | string  |          | `RELIFT_RUNTIME_DIR`                   | `--runtime-dir`                   | the C runtime sources to build against (empty: the ones beside this relift's source)                                                                                                                                                      |
| `color`                         | string  | `auto`   | `RELIFT_COLOR`                         | `--color`                         | color in output: auto (a terminal that shows it, and NO_COLOR unset), always or never                                                                                                                                                     |
| `toolchain.clang`               | string  |          | `RELIFT_TOOLCHAIN_CLANG`               | `--toolchain.clang`               | the clang driver                                                                                                                                                                                                                          |
| `toolchain.zig`                 | string  |          | `RELIFT_TOOLCHAIN_ZIG`                 | `--toolchain.zig`                 | zig, for `zig cc` player builds                                                                                                                                                                                                           |
| `toolchain.ninja`               | string  |          | `RELIFT_TOOLCHAIN_NINJA`               | `--toolchain.ninja`               | the ninja build tool                                                                                                                                                                                                                      |
| `toolchain.appimagetool`        | string  |          | `RELIFT_TOOLCHAIN_APPIMAGETOOL`        | `--toolchain.appimagetool`        | appimagetool, which packs the Linux release output                                                                                                                                                                                        |
| `toolchain.android-sdk`         | string  |          | `RELIFT_TOOLCHAIN_ANDROID_SDK`         | `--toolchain.android-sdk`         | the Android SDK with build-tools and platforms (empty: ANDROID_HOME, then common places)                                                                                                                                                  |
| `toolchain.android-ndk`         | string  |          | `RELIFT_TOOLCHAIN_ANDROID_NDK`         | `--toolchain.android-ndk`         | the Android NDK (empty: ANDROID_NDK_HOME, then the SDK's newest)                                                                                                                                                                          |
| `toolchain.codesign-identity`   | string  |          | `RELIFT_TOOLCHAIN_CODESIGN_IDENTITY`   | `--toolchain.codesign-identity`   | the identity that signs macOS game builds, such as a Developer ID Application certificate name or its SHA-1 (empty: an ad-hoc signature)                                                                                                  |
| `toolchain.codesign-keychain`   | string  |          | `RELIFT_TOOLCHAIN_CODESIGN_KEYCHAIN`   | `--toolchain.codesign-keychain`   | the keychain that holds the signing identity (empty: the default keychain search list)                                                                                                                                                    |
| `emit.shard-kib`                | integer | `4096`   | `RELIFT_EMIT_SHARD_KIB`                | `--emit.shard-kib`                | the most KiB of C per emitted file; clang needs about 120 bytes of memory per byte of C                                                                                                                                                   |
| `emit.piece-kib`                | integer | `1024`   | `RELIFT_EMIT_PIECE_KIB`                | `--emit.piece-kib`                | the most KiB of C per C function; a larger guest function is split into several                                                                                                                                                           |
| `emit.cold`                     | boolean | `true`   | `RELIFT_EMIT_COLD`                     | `--emit.cold`                     | also emit a cold copy of every function that dispatch enters at any instruction, so no guest code is missed                                                                                                                               |
| `emit.cold-piece-kib`           | integer | `4`      | `RELIFT_EMIT_COLD_PIECE_KIB`           | `--emit.cold-piece-kib`           | the most KiB of C per C function of the cold copy                                                                                                                                                                                         |
| `emit.cold-first`               | boolean | `false`  | `RELIFT_EMIT_COLD_FIRST`               | `--emit.cold-first`               | for tests: run every function from the cold copy, which then calls only itself                                                                                                                                                            |
| `emit.fpcr-guards`              | boolean | `false`  | `RELIFT_EMIT_FPCR_GUARDS`              | `--emit.fpcr-guards`              | for debugging: keep the FPCR guards of lifted code even when the build proves the FP mode constant (RELIFT_FP_EXACT=1 needs them)                                                                                                         |
| `package.appimage`              | string  | `auto`   | `RELIFT_PACKAGE_APPIMAGE`              | `--package.appimage`              | the desktop release output: an AppImage on Linux, a signed .app on macOS. auto (an AppImage when appimagetool is found), always (a Linux build without appimagetool fails) or never (no desktop package; the Android APK is always built) |
| `package.android-id`            | string  |          | `RELIFT_PACKAGE_ANDROID_ID`            | `--package.android-id`            | the application id of the Android APK (empty: dev.relift.game.<project folder>)                                                                                                                                                           |
| `package.android-keystore`      | string  |          | `RELIFT_PACKAGE_ANDROID_KEYSTORE`      | `--package.android-keystore`      | the keystore that signs the APK, with the key alias relift (empty: a debug key in the cache)                                                                                                                                              |
| `package.android-keystore-pass` | string  |          | `RELIFT_PACKAGE_ANDROID_KEYSTORE_PASS` | `--package.android-keystore-pass` | the password of the keystore and its key                                                                                                                                                                                                  |
| `package.notarize`              | boolean | `false`  | `RELIFT_PACKAGE_NOTARIZE`              | `--package.notarize`              | notarize a macOS game build with Apple (needs toolchain.codesign-identity and the notarize-* keys)                                                                                                                                        |
| `package.notarize-key`          | string  |          | `RELIFT_PACKAGE_NOTARIZE_KEY`          | `--package.notarize-key`          | the App Store Connect API key file (.p8) that notarization signs in with                                                                                                                                                                  |
| `package.notarize-key-id`       | string  |          | `RELIFT_PACKAGE_NOTARIZE_KEY_ID`       | `--package.notarize-key-id`       | the key ID of the notarization API key                                                                                                                                                                                                    |
| `package.notarize-issuer`       | string  |          | `RELIFT_PACKAGE_NOTARIZE_ISSUER`       | `--package.notarize-issuer`       | the issuer ID of the notarization API key                                                                                                                                                                                                 |
| `package.ios-id`                | string  |          | `RELIFT_PACKAGE_IOS_ID`                | `--package.ios-id`                | the bundle identifier of the iOS app (empty: dev.relift.game.<project folder>)                                                                                                                                                            |
| `package.ios-identity`          | string  |          | `RELIFT_PACKAGE_IOS_IDENTITY`          | `--package.ios-identity`          | the keychain identity that signs the iOS app for a device (empty: the first Apple Development identity)                                                                                                                                   |
| `package.ios-data`              | string  | `bundle` | `RELIFT_PACKAGE_IOS_DATA`              | `--package.ios-data`              | where an iOS app finds the game data: bundle (copied into the app, sealed by its signature) or documents (added later to the app's Documents, for example with relift push)                                                               |
| `package.ios-profile`           | string  |          | `RELIFT_PACKAGE_IOS_PROFILE`           | `--package.ios-profile`           | the provisioning profile of the iOS app (empty: one from Xcode's profile folders that covers the bundle identifier)                                                                                                                       |
